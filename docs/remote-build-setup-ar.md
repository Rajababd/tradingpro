# إعداد بيئة بناء سحابية لـ TradingPro

أُضيف سير عمل GitHub Actions في `.github/workflows/verify.yml` لتشغيل التحقق في بيئة Linux متصلة بالإنترنت، دون تعديل إصدارات اعتماديات التطبيق.

## ما الذي ينفّذه سير العمل؟

1. يثبّت Node.js `24.22.1`.
2. يثبت الاعتماديات باستخدام `npm ci` من ملف القفل.
3. يشغّل `npm run test:drawing` و`npm test`.
4. يشغّل فحص أنواع TypeScript والبناء الإنتاجي.
5. يثبت Chromium وPlaywright ويشغّل اختبار أدوات الرسم في نافذة سطح مكتب ونافذة هاتف.

## تشغيله

1. أنشئ مستودعًا جديدًا على GitHub، ويفضّل أن يكون **Private** إذا كان الكود غير مخصص للنشر العام.
2. ارفع محتويات هذا المشروع إلى جذر المستودع. لا ترفع `node_modules`.
3. افتح تبويب **Actions** في المستودع.
4. سيعمل سير التحقق تلقائيًا عند `push` أو `pull_request`، ويمكن تشغيله يدويًا عبر **Run workflow**.
5. راجع كل خطوة في سجل التشغيل؛ لا يُعد الدمج متحققًا إلا إذا نجحت جميع الخطوات، بما فيها اختبار المتصفح.

## ملاحظات

- لا يغيّر هذا الإعداد `package.json` أو `package-lock.json`.
- اختبار المتصفح يستخدم نسخة Chromium التي يديرها Playwright، بدل الاعتماد على مسار `/usr/bin/chromium` الخاص ببيئة معينة.
- هذا الملف يجهّز التشغيل السحابي، لكنه لا يستطيع إنشاء المستودع أو رفع الكود إلى حسابك دون تنفيذ ذلك من حساب GitHub الخاص بك.
